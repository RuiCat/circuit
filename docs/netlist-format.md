# 网表格式参考

## 语法

网表由元件定义行组成，每行格式为：

```
<类型><ID> [<引脚节点ID>,...] [<参数值>,...]
```

- **类型**：字母开头，如 `R`, `C`, `Q`, `V`, `D`, `X`
- **ID**：数字，类型后的唯一标识
- **引脚**：方括号内的逗号分隔节点 ID 列表，节点 ID 可以是任意非负整数（-1 表示地）
- **参数值**：可选的第二个方括号，逗号分隔的值列表

## 示例

```
R1 [1,-1] [1000]       # 电阻 R1, 引脚 1→地, 阻值 1kΩ
V1 [1,-1] [0,0,0,0,5]  # 电压源 V1, 引脚 1→地, 直流 5V
Q1 [2,3,-1] [false,100] # NPN 三极管, 基极=2, 集电极=3, 发射极=地, β=100
```

> ⚠️ **地节点是 `-1`,不是 `0`**。节点 `0` 是普通浮动节点;若电路没有引脚接 `-1`,
> MNA 矩阵奇异,仿真报 `matrix is singular or nearly singular`。
> 早期文档示例写作 `[1,0]` 系误导,以 `[1,-1]` 为准。

## 节点 ID

| ID | 说明 |
|----|------|
| `-1` | 地节点（全局参考点，电压为 0） |
| `0` `1` `2` ... | 普通电路节点，正节点 ID |
| 内部节点 | 由加载器自动分配，用户无需指定 |

> 节点 ID 可以是任意非连续整数（如 10, 11, 20, 100），加载器会自动重编号为紧凑连续索引。

## 注释

```
# 这是行注释（到行尾）
// 这也是行注释
/* 这是块注释 */
```

## 子电路定义

支持 `.subckt` / `.ends` 块定义可复用的子电路：

```
.subckt <名称> <端口1> <端口2> ...
  <元件定义>...
.ends <名称>
```

### 示例

```
.subckt nand a b out
  R1 [100,out] [1000]
  Q1 [a,1,0] [false,100]
  Q2 [b,1,0] [false,100]
.ends nand
```

### 实例化

使用 `X` 类型元件实例化子电路：

```
X1 [in1,in2,out] [nand]           # 实例化 nand 子电路
X2 [a,b,sum] [half_adder]         # 实例化 half_adder 子电路
```

### 嵌套

子电路支持嵌套定义（子电路内部引用其他子电路），加载器会递归展开所有嵌套并分配唯一内部节点 ID。

## 变量定义

支持 `.value` 命令定义变量，在元件定义中通过 `%变量名` 引用：

```
.value freq 1000
.value rval 10000

V1 [1,-1] [5,0,%freq,0,5,0.5]   # 引用 freq 变量
R1 [1,2] [%rval]                 # 引用 rval 变量
```

## 支持的值类型

| 类型 | 示例 | 说明 |
|------|------|------|
| 整数 | `0`, `100` | 枚举/计数参数 |
| 浮点数 | `5.0`, `1e3`, `1000` | 数值参数 |
| 布尔 | `true`, `false` | 开关/标志 |
| 字符串 | — | 预留 |

## 完整网表示例：RTL 半加器

```
# 电源
V1 [100,-1] [0,0,0,0,5]            # Vcc = 5V (DC)

# 输入信号 (脉冲波: bias=0, freq=20/10Hz, V_max=5, duty=0.5)
V2 [10,-1] [5,0,20,0,5,0.5]        # 输入 A
V3 [11,-1] [5,0,10,0,5,0.5]        # 输入 B

# NOR1: A NOR B → 节点 20
R1 [100,20] [1000]
R2 [10,21] [10000]
R3 [11,22] [10000]
Q1 [21,20,-1] [false,100]
Q2 [22,20,-1] [false,100]

# NOR2: A NOR U → 节点 30
R4 [100,30] [1000]
R5 [10,31] [10000]
R6 [20,32] [10000]
Q3 [31,30,-1] [false,100]
Q4 [32,30,-1] [false,100]

# NOR3: B NOR U → 节点 40
R7 [100,40] [1000]
R8 [11,41] [10000]
R9 [20,42] [10000]
Q5 [41,40,-1] [false,100]
Q6 [42,40,-1] [false,100]

# NOR4: P NOR Q → 节点 50 (XNOR)
# NOR5: XNOR NOR XNOR → 节点 60 (Sum)
# NOR6: A NOR A → 节点 70 (¬A)
# NOR7: B NOR B → 节点 80 (¬B)
# NOR8: ¬A NOR ¬B → 节点 90 (Cout = A∧B)
```

## 网表解析规则

1. 每行一个元件定义
2. 引脚数量和类型必须与元件定义匹配
3. 参数值可以部分省略（省略部分使用默认值）
4. 节点 ID `-1` 保留给地节点
5. 节点 ID 不要求连续（自动重编号）

### 物理域隔离（气 / 油 / 电）

气路、油路、电气是三套独立系统，同一节点只允许连接同一物理域的引脚：

- **电气域**：弱电引脚（电阻/电容/电源等）、强电引脚、布尔引脚（逻辑门/触发器）可互连；
- **气路域**：`PS`/`PR`/`PC`/`PL`/`PCV` 及压力传感器气路侧引脚；
- **液压域**：`HP`/`HR`/`HA`/`HL`/`HCV` 及压力传感器液压侧引脚。

跨域混接（如电压源与气源接同一节点）在网表加载时直接报错，不再静默产生无物理意义的结果。
全局地节点 `-1` 是共享参考点（电气地 0V、气路地=大气压、油路地=油箱），各域可共用。
跨域转换元件（`EP` 电气-气动、`EH` 电气-液压、`PSENS` 压力传感器）两侧引脚分属不同域，但连接不同节点，不受影响。

## 稳态分析网表子集（AC / 小信号）

`analysis` 包解析同一套 SPICE 风格语法，但仅支持以下子集（见 [powerflow.md](powerflow.md)）：

```
R1 [n1,n2] [R]                 # AC 导纳 1/R
C1 [n1,n2] [C]                 # AC 导纳 jωC
L1 [n1,n2] [L]                 # AC 导纳 1/(jωL)
V1 [n+,n-] [waveform,bias,frequency,phase,V_max]
   # waveform=0(DC): 相量 (V_max+bias)∠0°(小信号中短路)
   # waveform=1(AC): 相量 V_max∠phase°(小信号工作点中短路)
I1 [n+,n-] [I]                 # 相量 I∠0°(小信号中开路)
D1 [a,k] [Is,Vz,N,Rs,T]        # 二极管(小信号:工作点线性化 g_d)
U1 [in1,...,out] [type,V_high] # 逻辑门(小信号:输出短路、输入高阻)
```

- 稳态分析**不支持子电路**（`.subckt`/`X`）与其它元件类型
- 小信号工作点要求纯 DC 电路（含 C/L 报错）
- AC 分析要求电路至少一个引脚接 `-1`（浮空电路无唯一解）

## 潮流网表子集（B/BR）

电力系统潮流使用独立语法（`analysis/powerflow/netlist.go` 解析），与元件网表互斥，
CLI 自动识别（第二词元为 slack/pv/pq 或 `BR<id>` 前缀）。全部标幺值，键大小写不敏感：

```
B<id> slack [V=..] [Theta=..]                     # 平衡母线: V 必给, Theta 默认 0(度)
B<id> pv   V=.. P=.. [Qmin=..] [Qmax=..]          # 发电机母线: V、P 必给, 无功限幅可选
B<id> pq   P=.. Q=..                              # 负荷母线: P、Q 必给
BR<id> From-To [R=..] [X=..] [B=..] [Tap=..]      # 支路: R/X 必给且不可同时为 0
```

```
B1 slack V=1.05
B2 pv   V=1.0 P=0.5 Qmin=-0.3 Qmax=0.3
B3 pq   P=-1.0 Q=-0.5
BR1 1-2 R=0.01 X=0.1
BR2 1-3 R=0.01 X=0.1
BR3 2-3 R=0.01 X=0.1
```

> 注意：元件引擎也有类型 `B`（EventSwitch 开关，语法 `B1 [1,0] [...]`），
> CLI 仅当第二个词元为 slack/pv/pq 时判定为潮流母线，普通开关网表不受影响。
> 完整说明见 [powerflow.md](powerflow.md) 第 3 节。
